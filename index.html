Project Overview & Key Features

Designed an end-to-end computer vision system to automate data entry from Egyptian National Identity Cards, eliminating manual typing errors and saving administrative processing time.

  • YOLOv8 ROI Detection: Fine-tuned a YOLOv8 object detection model to isolate specific regions of interest (ROI) such as Name, National ID number, address, and expiration date regardless of orientation or lighting.
  • Advanced OCR Integration: Applied image preprocessing (grayscale, adaptive thresholding, deskewing) and OCR engine pipelines to extract Arabic and numeral text.
  • Structured Excel Output: Automated conversion of extracted card data directly into structured database formats and Excel spreadsheets.
